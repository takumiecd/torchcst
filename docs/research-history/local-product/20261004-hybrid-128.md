# 128-site transforms and per-atom hybrid H

Research branch `codex/local-product-hybrid`, parent `32330a9`.

The user requested N128 experiments and a single operator combining local and
saved H. Local domains/slices now accept up to128 sites per side, with the same
full-domain normalization cap128 and batch cap64. The benchmark adds N128/B32,
A819 (round(0.05*128*128)) fixtures in the existing Linear runner. Production
Strip/Torus dispatch and the mathematical kernel are unchanged.

## Hybrid policy

The existing recipe boundary array supplies the policy: `rho_upper[0]` is the
local/saved cutoff for the hybrid route. For example `(4,16)` uses local H for
rho=sigma/spacing <=4 and saved H for rho>4. Comparison plans also use cutoffs2
and8. This reuses configurable boundaries without hardcoded narrow/medium/wide
names or changing existing serialized recipe fields.

Every forward prepares normalized metadata from current polar parameters.
Precision `1/sigma^2` selects each atom's route on the device:

1. A producer computes and stores H only for wide atoms. Completely narrow atom
   blocks skip its input contraction. Mixed blocks mask narrow factor lanes.
2. The output kernel computes narrow H locally and reads wide H from scratch,
   then contracts their contributions together into the same Y accumulator in
   canonical atom order. Completely wide blocks skip the local input dot.
3. Parameter VJP uses the same classification saved in this forward's metadata:
   recompute narrow H, reuse saved wide H; compute required center derivatives.
   dX uses the existing transposed local contraction (G is not separately cached).

This is one hybrid operator, implemented by several kernels with a dependency
through wide-H scratch. It is not a single kernel spanning independent CTAs.
No W or full U/V matrix is materialized. Sigma task derivatives remain detached;
PolarAmpWidth activity/radial updates continue to change sigma each step.

Scratch has fixed capacity B*A so CUDA Graph replay can change route counts
without a host synchronization or allocation decision. Only wide lanes are read
or written, but capacity is **not compacted**: it does not claim lower allocated
scratch than all-H storage. In mixed blocks, masked matrix dots still evaluate
padded lanes. Spatial/width grouping and compaction remain optimization work.
L1/L2 residency is neither allocated nor guaranteed by this prototype.

Forward/dX and parameter contractions use8 warps when either local side exceeds
64, otherwise the previous4. Prepare/save-H/from-H retain4. Actual register/spill
and shared-memory reports determine whether this choice works on L4.
