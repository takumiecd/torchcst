# RTX 4090のrational-radiusディスパッチ更新

[English](rational-wide-dispatch-refresh-4090-20261120.md) | **日本語**

選択表の対象は、正方のM8 rational-radius Linear、入力128行、eagerのIEEE FP32で、
入力とAtomの両方に勾配が必要な場合。RTX 4090、Torch 2.9.1+cu128、
Triton 3.5.1に対応する。[Neonの生成依頼](../../../benchmarks/dispatch/requests/rational-wide-rtx4090-v2.json)
は、Planごとの独立した2実行から完全ステップ時間の中央値を取り、順位を決める。
ライブラリは生成済みの完全一致表をローカルで参照する。

## 標準ベンチマーク

標準ランナーは初期化したAtomと固定のMSEターゲットを使い、
eagerのCSTAdamWで8更新のウォームアップ後に24更新を測定した。
通常のDense対照は同じ有効重みから始め、AdamWを使う。各欄はoptimizer込みの
時間（ms）と、計測中の最大ピーク割当（MiB）。測定原本とleaderboardには
アロケータのピーク予約も記録している。

| 幅とAtom数 | CSTフーリエ展開 | 従来のCST直接 | タイル順のCST直接 | 通常のDense | 選択Plan |
| --- | ---: | ---: | ---: | ---: | --- |
| 2048 / 32N | 2.63 / 171 | 18.18 / 119 | — | 0.43 / 85 | フーリエ展開 |
| 4096 / 32N | 7.68 / 590 | 35.39 / 237 | 5.62 / 241 | 1.01 / 282 | タイル順の直接 |
| 8192 / 16N | 22.10 / 2210 | — | 5.95 / 321 | 4.08 / 1060 | タイル順の直接 |
| 8192 / 32N | 24.93 / 2243 | — | 9.57 / 482 | 4.07 / 1060 | タイル順の直接 |
| 16384 / 32N | 85.83 / 8766 | — | 17.21 / 963 | 14.24 / 4152 | タイル順の直接 |

10実行すべてで全サイト・全AtomのFP64参照照合に通った。
幅16384のピーク予約はタイル順の直接版で1252 MiB、フーリエ展開で9870 MiB、
通常のDenseで4198 MiBだった。

## 学習済みチェックポイントの再現

RTX 4090上で通常の `CSTLinear(x)` を通し、5条件すべてで表のPlanが選ばれた。
出力・入力勾配・Atom勾配を同じPlanの明示指定と比較した際の最大相対L2差は
`2.54e-8`。初回はビット一致を要求し、幅2048の展開版でFP32の加算順による差を検出した。
再検証では `rtol=4e-5, atol=2e-6` で照合した。

TinyStoriesのseed 17、更新4,882時点のQuery Atomを合成入力で再現した。
拡幅条件では同じ学習済みAtomをより広い格子に配置した。4条件で展開版とタイル順の
直接版の出力・勾配を比べ、最大相対L2差は `2.12e-6`。時間は実行順を入れ替えた
2回の中央値の平均と、最大ピーク割当を示す。

| チェックポイントの再現 | フーリエ展開の更新 / MiB | タイル順の直接版の更新 / MiB |
| --- | ---: | ---: |
| 4096 / 32N | 6.25 ms / 614 | 6.80 ms / 281 |
| 16384 / 32N（拡幅） | 78.55 ms / 8938 | 18.30 ms / 1111 |

幅4096では初期化時の速度で直接Planが選ばれ、学習済みQueryでは更新が0.55 ms増え、
ピーク割当が54%減った。完全一致表は演算と実行環境のメタデータを参照する。
Swin-MLP、Keyword-MLP、MTGNN、PatchTSTの各実験はPolar座標と別の演算を使う。
公開済みの残差CNNは展開済みの分類器重みを使う。ここでは対象のLinear射影と
短い更新を再現した。
