# 現行sigmaからLを選ぶときの固定幅tile参照数

2026-10-21、branch `kernel/hierarchical-fourier-tiles`、runtime source `1cd1cd82`。
`DyadicFourierSpec`のsigmaの意味・係数・支持を変えず、Lの選択とtile参照数を数える。
速度、GPU通信、hierarchy nodeの訪問数、保存容量の測定ではない。

## 条件と数え方

spacing h=.1、L_min=.4、level_ratio=.85、overlap=.12。
各成分の支持は|x−mu|<L、端点は値0なので参照集合から除く。
タイルは原点0、幅Tで、tile j=[jT,(j+1)T)。T/hは整数。
領域の端による切り出しはせず、無限格子または十分内側のatomを考える。
M4/8の`scale_weights`を直接呼び、全例で同じL・混合係数を返すことを確認した。
Mを変えると計算量・形は異なるが、このL選択と支持tile数は変わらない。

格子x_i=ihの支持内の最初・最後のindexは

\[
i_{\min}=\left\lfloor\frac{\mu-L}{h}\right\rfloor+1,\qquad
i_{\max}=\left\lceil\frac{\mu+L}{h}\right\rceil-1.
\]

非空ならtile IDはfloor(i_min/(T/h))からfloor(i_max/(T/h))まで。
各小数を厳密な有理数として数え、丸め誤差で端点を追加しない。
幅・中心の252条件で、整数siteを直接列挙した結果と一致することをassertした。
実際の浮動小数点実装のulpによる端点判定を数えたものではない。

混合する二成分の支持は同じ中心を持ち入れ子なので、入力tile集合のunionは最大Lで決まる。
ただし周期が違うmomentと係数処理は別であり、union個数だけで計算量は決まらない。
小さい正の混合係数や小さい裾は切り捨てない。

## sigmaとLの移行区間

Lから2Lへの混合は、sigmaが.85L(1±.12)/sqrt(11)の間で行う。

| 使用L | 混合開始sigma | 混合終了sigma |
| --- | ---: | ---: |
| .4 → .8 | .0902121943 | .1148155200 |
| .8 → 1.6 | .1804243886 | .2296310400 |
| 1.6 → 3.2 | .3608487772 | .4592620801 |
| 3.2 → 6.4 | .7216975544 | .9185241601 |
| 6.4 → 12.8 | 1.4433951088 | 1.8370483202 |

正確な開始点では大Lの重み0、終了点では小Lの重み0。
開始点の直後に大Lの参照tileが追加される場合があるが、関数とsigma勾配は滑らかにつながる。
例えばsigma=.1ではF=.686312407*F_.4+.313687593*F_.8。
sigma=.12/.15はL=.8単独、sigma=.3はL=1.6単独。

sigma=.1,.2,.4,.8,1.6,3.2の混合では、いずれも小L/大Lの重みは約68.6%/31.4%。
Lはsigmaだけで決まり、中心がtile境界をまたぐことを理由に増やさない。
Tを大きくすると参照tile数は減るが、各tileで準備するsite数と部分tile処理も考慮する必要がある。
「1tile参照」は、その全siteをatomごとに直接計算することを意味しない。

## 境界をまたぐ具体例

sigma=.15、L=.8、T=.8。tile0=[0,.8)、tile1=[.8,1.6)、tile2=[1.6,2.4)。
負のtile IDも領域内にある相対座標の例として扱う。

| mu | 支持端(mu−L,mu+L) | 参照tile ID | 実site参照tile数 | 連続区間として触れる数 |
| ---: | --- | --- | ---: | ---: |
| .400 | (−.400,1.200) | −1,0,1 | 3 | 3 |
| .775 | (−.025,1.575) | 0,1 | 2 | 3 |
| .800 | (.000,1.600) | 0,1 | 2 | 2 |
| .825 | (.025,1.625) | 0,1,2 | 3 | 3 |

mu=.775では負側の隣接tileに少し支持が入るが、その部分には格子点がない。
mu=.825ではx=1.6が支持内に入り、tile2が必要になる。
mu=.8ではx=0,1.6は値0の支持端。新しく入るsiteの値は0から連続に立ち上がり、
参照集合の切替が山の値や勾配の飛びを意味するわけではない。

## 混合成分の参照と入力tileの共有

sigma=.1、T=.8の場合：

| mu | L=.4の参照数 | L=.8の参照数 | 成分別の合計 | 入力tileのunion |
| ---: | ---: | ---: | ---: | ---: |
| .400 | 1 | 3 | 4 | 3 |
| .800 | 2 | 2 | 4 | 2 |
| .825 | 2 | 3 | 5 | 3 |

入力tileの読み取りは共有できる余地があるが、二周期のmomentを同じ値とは扱わない。
階層nodeへの分解、追加周波数、準備、H、Y/dX、L2の費用はこの表には含まない。

2次元のprofile productでは軸ごとに同じ計算を行い、
支持内格子点を持つ物理tileの個数はN_x*N_yとなる。
例えば両軸sigma=.15、T=.8なら中心位置により4/6/9tile。
T=3.2なら1/2/4tile。混合成分数や周波数対の処理量は別に数える。
