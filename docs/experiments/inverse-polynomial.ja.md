# JᵀDJの逆作用を少数回の作用で近似できるか

2026-09-09。対角・atom内ブロックでスケールを整え、固定次数の多項式で逆作用を近似する
精度の可能性を調べた。公開optimizerを変更せず、近似解を学習には適用していない。

## 対象とoracle

前回と同じA100・MNIST・64 atoms / 256 parameters・seed17。
384更新を行い、32/128/384更新目のfactor、separable D、補正済み右辺を保存した。
384更新すべて検査合格。全49評価地点の正解数は元の試行と一致した。
学習の計測中に診断用入力を保存したため、今回の学習時間は性能比較に使わない。

Hは実装に合わせて `J.T D J / lr`、右辺はバイアス補正済み一次momentの負値。
保存したネイティブ微分factorをFP64へ昇格し、CPUで独立に可視Jacobianを構成した。
`J.T @ (D * J)`による作用は、GPUのfactor-owned JVP/VJP作用と
相対差2.4e-15〜3.3e-15で一致した。数学的な微分の独立autograd再検証ではない。

Hそのものと、trust半径0.25に対応する正確なshift μを与えたH+μIを分けて分析する。
shiftは診断用のFP64固有分解で求めた。公開spectral経路のFP32 Gramと丸めまで同一ではない。
正規化前のHの最小固有値が最大の1e-12以下なら、数値的特異として逆近似を評価しない。
これは厳密な数学上の非可逆性の証明ではない。

## 多項式と前処理

Aを対象行列、PをI・diag(A)・atom内4×4ブロックのいずれかとして、
B=P^(-1/2) A P^(-1/2)と変換する。前処理で非対角の相互作用は削除しない。

Bの正確な最小・最大固有値a,bを与える、有利な条件で比較した。

- Neumann/Richardson：残差多項式 `r_m(λ)=(1-2λ/(a+b))^m`。
  固定ステップ幅は区間上の最大収縮率を最小化する値。
- Chebyshev：`r_m(λ)=T_m((d-λ)/c)/T_m(d/c)`、d=(a+b)/2、c=(b-a)/2。
  スペクトル区間上の残差を小さくする多項式。特定の右辺の残差を直接最小化するものではない。

作用回数予算1/2/4/8/16/32/64/128について、固有座標上で多項式解を評価する。
各近似解を元の座標へ戻し、`||Ax-b||/||b||`、直接解との相対差を計算する。
このdegreeは固定反復実装の作用回数予算に対応するが、今回は固有座標での精度oracleであり、
matrix-free実装の実測速度・メモリを示すものではない。固有分解、前処理、shift探索の費用も
無料で与えている。小さい行列でも実用上有利になることを保証しない。

## 結果

生のHの条件数は、128更新目で約1.1e11、384更新目で約5.7e11。
32更新目は相対閾値1e-12で数値ランク255/256だった。
128/384更新目ではatomブロック前処理後も条件数は約3.9e6 / 9.8e5残った。
Hを局所的にスケール調整するだけでは、逆作用が少数回で求まる形にはなっていない。

trust shiftは32/128/384更新目で約0.285 / 0.0405 / 0.0207。
H+μIについては以下。残差は元の座標で評価した値。

| 更新時点 | diag後条件数 | atom block後条件数 | diag＋Neumann 8回の相対残差 | diag＋Chebyshev 128回 | block＋Chebyshev 128回 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 32 | 1,231 | 1,106 | 0.146 | 9.90e-4 | 6.93e-4 |
| 128 | 1,353 | 1,191 | 0.252 | 1.28e-3 | 7.56e-4 |
| 384 | 865 | 751 | 0.141 | 2.72e-4 | 1.43e-4 |

全候補で、8回時点の最良相対残差は約0.14。128回まででも、今回比較した
全時点・前処理・方式で1e-5に到達したものはなかった。
32更新目では前処理なしChebyshev128回が約6.5e-5で、局所前処理より良い。
前処理は常に条件数や実残差を改善するわけではない。

## 判断

今回の実入力では、diag・atom blockを使った少数回のNeumann/Chebyshev作用を
正確な求解の代わりにする根拠は得られなかった。
これは「逆近似がすべて不可能」「この誤差なら学習も失敗する」という結論ではない。
低ランク補正、異なる多項式、近似更新を許容した学習などは別の実験になる。
特にCGの右辺適応型の多項式と今回の区間に基づく多項式は同一ではない。

現在の主要ボトルネックは再圧縮のG+δIであり、今回対象の更新側Hとは違う。
この結果から再圧縮の高速化率を推定してはいけない。
次に時間を評価する候補としては、小規模の直接法比較が残る。
